Dziennik prezentów

made by sinihiro

Zaznacz wszystko, co postać dostała tym razem, i zapisz. Kategoria (uwielbia / lubi / nie lubi / nienawidzi) dobiera się sama. Przedmioty, których postać nie przyjmie, są ukryte.

Lista przedmiotów

Kliknij przedmiot, żeby ukryć go w „Dodaj prezenty” albo dodać do listy. Zmiany zapisują się od razu i dotyczą wszystkich postaci.

Import z gry

Kliknij „Importuj folder assets” i wskaż folder assets z gry. Wszystko dzieje się lokalnie, nic nie jest wysyłane.
